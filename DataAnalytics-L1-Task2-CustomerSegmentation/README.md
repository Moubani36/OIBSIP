# Customer Segmentation Analysis

This project is completed as part of the **Oasis Infobyte Data Analytics Internship (OIBSIP).**

**Status:** ✅ Completed

---

## 📌 Objective

The objective of this project is to perform **Customer Segmentation Analysis** using the **K-Means Clustering** algorithm. Customers are grouped based on their purchasing behaviour using **RFM (Recency, Frequency, Monetary)** analysis, helping businesses create targeted marketing strategies.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook / Google Colab

---

## 📂 Dataset

* **Dataset:** Online Retail Dataset (UCI / Kaggle)
* **Records Used:** 392,692 transactions after data cleaning
* **Customers Analysed:** 4,338

---

## 📊 Project Workflow

* Data loading and inspection
* Data cleaning and preprocessing
* Feature engineering
* Descriptive customer statistics
* RFM (Recency, Frequency, Monetary) analysis
* Data standardization using StandardScaler
* Elbow Method to determine optimal K
* K-Means clustering
* Cluster visualization
* Cluster profiling
* Marketing recommendations

---

## 📈 Visualizations

* Elbow Method Plot
* Recency vs Monetary Scatter Plot
* Frequency vs Monetary Scatter Plot
* Customers per Cluster Bar Chart

---

## 📋 Customer Segments Identified

| Cluster   | Customer Type                  | Characteristics                                                     |
| --------- | ------------------------------ | ------------------------------------------------------------------- |
| Cluster 0 | Inactive / Low Value Customers | High recency, low purchase frequency, low spending                  |
| Cluster 1 | Regular Customers              | Moderate recency, moderate purchase frequency, moderate spending    |
| Cluster 2 | VIP Customers                  | Very recent purchases, highest purchase frequency, highest spending |

---

## 💡 Marketing Recommendations

### 🔹 Cluster 0 – Inactive Customers

* Re-engagement email campaigns
* Discount coupons
* Personalized promotional offers

### 🔹 Cluster 1 – Regular Customers

* Loyalty reward programs
* Product recommendations
* Cross-selling and upselling

### 🔹 Cluster 2 – VIP Customers

* Exclusive premium offers
* Early access to new products
* VIP membership benefits
* Dedicated customer support

---

## 📌 Key Insights

* Most customers belong to the **Regular Customer** segment.
* A small group of **VIP Customers** contributes significantly to overall revenue.
* **Inactive Customers** can be retained through personalized marketing campaigns.
* RFM-based clustering enables businesses to optimize customer retention and increase profitability.

---

## 🚀 Outcome

Successfully segmented customers into meaningful groups using **K-Means Clustering** and **RFM Analysis**, providing actionable insights for customer relationship management and targeted marketing.
